## 🚀 How to Use

### 🔧 Requirements
- GCC compiler or any C compiler
- Text editor (VS Code, CodeBlocks, or terminal)

### ▶️ Compile & Run

```bash
# Compile
gcc filename.c -o program

# Run
./program
```
